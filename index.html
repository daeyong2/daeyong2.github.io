Portfolio project

Watt What

에너지 절약을 미션과 보상으로 돕는 웹 서비스입니다. 사진 인증을 사용하는 행동 미션과 퀴즈·학습을 통한 정보 미션을 제공하고, 참여에 따라 포인트를 쌓을 수 있습니다.

주요 기능

미션 탐색, 사진 인증, 사용자 반응, 친환경 정보, 포인트 보상과 레벨 기능을 포트폴리오에 정리했습니다.

프로젝트 기술 스택

React, Tailwind CSS, Spring Boot, MySQL. 협업 도구로 Notion과 GitHub를 사용했습니다.

프런트엔드 작업

Create React App에서 Vite로 개발 환경을 옮기고 폴더 구조를 정리하며 리팩터링했습니다.
